# 원문과 지식 검수

## 전체 단위 대응

목차와 본문 경계에서 실제 장/주제 단위를 확인한다. 자동 감지한 제목 개수는 장 수가 아니다. chapters 폴더, chNN 이름, PDF, 특정 장 수를 가정하지 않는다. 서문·부록 제외는 사유와 범위를 남긴다. 기존 자료 구조를 보존한다.

inventory에 안정적인 단위 ID, 원문 파일/위치, 대응 스킬 파일, mapped/missing/excluded 상태와 사유를 기록한다. expected_unit_ids는 실제 목차 검토에서 정한 목록이다. 같은 목록 두 개를 생성했다는 것만으로 완전성이 증명되지 않으므로 source-reviewer가 원문에서 직접 확인한다.

mapped는 대응 파일을 찾았다는 뜻이며 내용 전체의 반영을 증명하지 않는다. 원문의 핵심 요소를 대응 파일의 실제 문장과 각각 대조하고, 없는 요소는 누락으로 표시한다. 원문에만 있는 내용을 대응 파일에도 있는 것처럼 쓰지 않는다. 색인·깨진 링크 같은 패키지 검수 항목은 원문 단위와 구분해 기록한다.

링크 대상의 부재는 실제 목록·검색·명확한 파일 없음 오류 등으로 확인한다. 이름이나 링크 문자열만 보고 없다고 단정하지 않는다. 권한 오류와 파일 부재를 구분하고, 실제로 확인하지 못한 경로는 미확인으로 남긴다.

## 주장과 귀속

| origin | 의미 | 근거 |
|---|---|---|
| author | 책의 직접 설명 | 원문 파일·장/절/쪽 |
| synthesis | 여러 설명을 스킬용으로 합성 | 관련 원문 위치와 합성 표시 |
| validation-guidance | 시험에서 검증한 적용 지침 | 오류 ID·실행 기록·적용 범위 |
| proposal | 새 응용·프로젝트 제안 | 가상 입력·미정 선택 |

원칙·방법·조건·예외·범위·예시 수치와 핵심 도구를 대조한다. 요약에서 중요한 방법이 빠지거나 근거 없는 규칙이 생기면 위치·영향·수정 제안을 남긴다. 원문 전체 문장을 복제하지 않는다. 사례를 보편 규격으로 승격하지 않는다.

원문 내부 모순은 양쪽 위치와 한계를 기록하고 한쪽을 임의 선택하지 않는다. 적용 정책은 선택지/결정 질문으로 분리한다. 확정 조건을 미정 응답·저장 기술과 함께 흐리지 않는다.

## 시각·추출 범위

원본 SHA-256, 실제 추출 방식, 폴백, OCR/표/수식 누락 가능성을 기록한다. 기존 추출물은 원본과 추출 설정의 동일성이 확인될 때만 재사용한다. 사라진 임시 경로를 유효한 근거로 기록하지 않는다.

시각 후보는 중요한 주장에 쓰인 표/그림 → 텍스트와 충돌하는 수치/관계 → OCR/열 정렬이 의심되는 자료 순으로 고른다. 모든 후보의 선택/미선택 사유, 실제 점검 위치와 캡처/렌더 SHA를 남긴다. 관련 자료가 없으면 none-identified로 기록한다. 심각한 표본 오류는 관련 점검 범위를 넓히되 전수 검수처럼 보고하지 않는다.

PDF 인덱스와 인쇄 쪽수는 각각 원문에서 확인한다. 다른 책에 일정 오프셋을 재사용하지 않는다. 원문 전체·이미지 전체·비밀 데이터는 배포 자료에 포함하지 않는다.

## 지식과 탐색 보완

입증된 오류·핵심 누락만 수정한다. 장 파일이 이미 참조 자료이면 무조건 이동하지 않는다. 자료 선택이 어려우면 질문/목적 → 파일/절 → 예상 산출물의 색인을 보강한다. 기존 용어·패턴·판단표를 연결하고 같은 내용을 복제하지 않는다.

행·키·중복 범위 같은 도메인 지침은 해당 도메인에 유지한다. 이 범용 후속 스킬은 검증 기반 지침을 저자 원칙으로 잘못 귀속하지 않는 규칙만 갖는다.
